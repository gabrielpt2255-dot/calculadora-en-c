# Calculadora en C

Programa de consola que realiza las cuatro operaciones básicas (suma, resta, multiplicación y división) mediante un menú interactivo.

## ¿Qué problema resuelve?
Permite hacer cálculos básicos desde la terminal, validando entradas incorrectas y evitando la división entre cero. Fue desarrollado como práctica de sentencias de control en C.

## Tecnologías
- Lenguaje C
- Compilador GCC (o el IDE ZinjaI)

## Conceptos aplicados
- Menú repetitivo con `do-while`
- Selección de operación con `switch`
- Condicionales (`if`) para validar datos
- Entrada y salida con `scanf` y `printf`

## Cómo instalar y ejecutar
1. Descarga el archivo `calculadora.c`.
2. Compila:
   ```
   gcc calculadora.c -o calculadora
   ```
3. Ejecuta:
   ```
   ./calculadora
   ```
   (En Windows: `calculadora.exe`)

También puedes abrir `calculadora.c` en ZinjaI y presionar **Ejecutar**.
